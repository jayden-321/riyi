# Apple 健康训练导入

日益在打开 App 或进入训练页时，对 HealthKit 的 Workout 类型执行增量读取；已存在于本机健康缓存、结束于近 7 天内的外部训练也会补入。导入记录使用 HealthKit UUID 派生固定 ID，状态为「已完成」，在训练日历当天和首页显示。HIIT 等运动按 HealthKit 的实际起止时间及 `duration_seconds` 记录，不虚构动作组、重量或次数；活动能量仅在 HealthKit Workout 实际提供时显示。

日益自己写入的 Workout 带有会话标记，或可由本 App 的来源识别，不再次导入。HealthKit 样本与训练记录通过 UUID 关联：重复读取不会重复建记录；HealthKit 删除样本后撤销对应的导入记录；服务器日报也不把同一场同时计作原始 Workout 和 App 训练。没有读取授权或超出获准历史范围时，不把缺失解释成没有训练。

导入记录不会自动改写既有计划；训练日历可按唯一运动大类展示在对应计划下，否则列于「当天已练记录」。近期导入范围限制在 7 天，避免首次升级时突然将整个健康档案的旧训练都变成新的日益记录。
